Why skills

Prompts drift. Skills don’t.

Instructions retyped from memory change every session, and so does the output. A skill is a written workflow your agent loads by name.

Before Ad-hoc prompt

  • Retyped each session, worded differently each time
  • Lives in chat history
  • Skips checks when time is short
  • Rebuilt for every tool and project

After Agent skill

  • Written once, versioned with semver
  • Installed as files, globally or per project
  • Same steps, templates, and checks on every run
  • One format across seven agent tools
How it works

Three steps. One command.

01

Pick your skills

Browse seven categories, from code review to App Store listings.

02

Install them

Tick several in asm’s picker, or name one. asm places them where your agent looks, globally or per project.

03

Call it by name

Your agent loads the skill and follows its steps, templates, and checks.

asm
# install asm once (Node.js 22+)
$ npm install -g agent-skill-manager
# pick several skills at once: Space to tick, Enter to install
$ asm install github:luongnv89/skills
# or add one skill directly
$ asm install github:luongnv89/skills:skills/code-review
# or start with every skill ticked
$ asm install github:luongnv89/skills --all
# search the catalog and see what you have
$ asm search "code review"
$ asm list
npx
# one skill
$ npx skills add https://github.com/luongnv89/skills --skill code-review
# several at once
$ npx skills add https://github.com/luongnv89/skills --skill code-review --skill auto-push --skill test-coverage

What you get

Built like software, not like a prompt.

01

Standalone

Install code-review alone or ten skills together. Each one ships as its own folder, with nothing shared at runtime.

<name>/
├── SKILL.md

02

One command

asm’s picker installs every skill you tick, in one pass. Paths handled for seven agent tools.

03

Versioned

Semver and a changelog for every skill.

04

Structured

Steps, templates, checklists, and self-validation, written down.

05

Light on context

The agent reads SKILL.md first and loads references only when the task needs them.

06

Suites

FAQ

Common questions

Do I need every skill?
No. Each skill is independent. Install only what your project needs.
Which agents work?
Any tool that loads skill files. The installer handles paths for Claude Code, Cursor, Windsurf, GitHub Copilot, OpenAI Codex, OpenCode, and Google Antigravity.
How is a skill different from a prompt?
A skill is a versioned workflow with references, templates, and quality checks, stored as files. A prompt is a one-off instruction in chat history.
Does it touch my runtime code?
No. Skills guide your agent during development. Nothing ships with your app.
Can I write my own?
Yes. Follow CONTRIBUTING.md and the authoring guide. The same format and validation tools apply.
Is it free?
Yes. MIT licensed.
