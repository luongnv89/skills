Brand Identity

AGENT SKILLS

Plug in. Power up.

A brand identity for plug-and-play agent capabilities — a skill card seated in the agent ring, forming the universal power-on symbol.

Design Concept

The Keyed Slot

One symbol, one idea: the moment a skill is loaded, the agent powers on.

1 2 3
  1. Skill card
    the chamfer and contacts make it a memory card
  2. Keyed slot
    the ring is cut parallel to the card with a uniform clearance
  3. Agent ring
    an open loop; card + ring = the power-on symbol

“I know kung fu.” The mark is inspired by The Matrix: Tank loads a program, Neo opens his eyes, and he is instantly capable. A skill is plugged in — the agent powers on with a new ability.

Plug in, power up. A chamfered memory card seated in an open agent ring reads as the universal power symbol — the instant a skill connects, the system comes alive.

Engineered fit. The keyed cut in the ring runs parallel to the card with a uniform clearance — a precise, plug-and-play socket rather than decoration.

Color as signal. Phosphor #00FF41 is the Matrix code green and the “powered on” LED — it lives only on the card, and only on dark surfaces. On light backgrounds the mark switches to Phosphor Deep #008F11, where pure phosphor is too weak.

Calm counterweight. The wordmark is tracked caps in Instrument Sans Medium — quiet, premium typography against the bold mark, and the same typeface as the docs site.
