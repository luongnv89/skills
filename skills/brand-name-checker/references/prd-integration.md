# PRD Integration

Apply this section only when a `prd.md` file exists in the project. Append both blocks after the compact report in `SKILL.md` → *Output Format*. Keep the compact report's `RISK:` and `RECOMMEND:` lines unchanged; callers such as `product-planner` read them.

## Name Fit Assessment

Rate the name against the PRD on three points. Quote the PRD line each rating relies on.

- Alignment with the product vision
- Memorability, pronunciation, and spelling
- Fit with the target audience
