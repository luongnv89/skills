# Quillpad 1.0 is out

Quillpad is a distraction-free Markdown notebook for the terminal.

## What's in 1.0

- Full-text search across every notebook
- Encrypted sync through any folder (Dropbox, Syncthing, iCloud Drive)
- Vim and Emacs keybindings

## Install

    brew install quillpad

Source code and issues: https://github.com/example/quillpad
