# Edge Cases

Handling rules for unusual inputs and source failures. `SKILL.md` → *Edge Cases* links here; the risk policy in `SKILL.md` → *Step 5: Risk Assessment* always wins over anything below.

- **Exact social handle taken on any of the 6 platforms**: apply the Early-Exit Rule. Skip all remaining checks, report them as `Skipped (not cleared)`, and return an Abandon recommendation with alternative name suggestions labeled unverified.
- **Rate-limited registry API** (HTTP 429 or a rate-limit message): retry once after 5 seconds. If it is still blocked, mark the registry as "unchecked"/unknown and note it in the report — do not skip silently. Apply the unknown policy; do not infer availability.
- **Trademark register blocks automation or shows stale results** (a bot check, a `Request Rejected` page, an app shell, or results that do not name the searched term): mark that register unknown, never clear or conflicting, and give its manual check link from `references/source-checks.md` → *Step 4*. A hit whose word element does not match the name is not a conflict.
- **Trademark database unavailable**: note the outage per database and mark the affected check unknown. Do not lower a known High finding. Without a known High finding, use provisional Moderate + Modify pending verification.
- **Name contains special characters or spaces**: normalize to slug form (letters `a-z`, digits and `-`, starting and ending with a letter or digit; for example `my tool` → `my-tool`) before all checks, and report both the original and the normalized forms.
- **Several names in one request**: commas, semicolons and newlines separate names; spaces and the words `and`, `or` and `vs` never do (`Salt and Pepper` is one name). A comma item that is a company suffix (`Inc`, `Inc.`, `LLC`, `Ltd`, `GmbH`, `SAS`, `SA`, `Co.`) joins the name before it, so `Acme, Inc.` is one name. A name passed by another skill is one name, never split. Empty items are dropped, names with the same slug are checked once, and names past the 5-name cap are listed as not checked (`references/output-contract.md` → *Several names*).
- **Very short names (1-3 characters)**: flag the elevated trademark collision risk upfront. Abbreviations are almost always claimed across social and trademark databases.
- **Name already in use by a well-known brand (typosquat risk)**: escalate to High even if every technical check passes.
- **No web access** (no HTTP or search tool answers a test request): return the `BLOCKED` report from `SKILL.md` → *Output Format*. Never fill statuses from memory. When only one kind of tool works, run the checks anyway and mark each source it cannot reach Unknown.
