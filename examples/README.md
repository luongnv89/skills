# Examples

Worked examples of skills from this catalog, each run for real on a real project. Every folder keeps the full material from its run, including intermediate artifacts, decisions, and final outputs, so you can see how the skill behaves and not only what it produces.

These folders sit outside `skills/`, so the installers never copy them into your agent.

| Example | Skill | What it shows |
|---|---|---|
| [logo-designer/](logo-designer/) | [`logo-designer`](../skills/logo-designer/) | The Agent Skills logo, from brief to 26 concept sketches, a concept board, user decisions, 7 validated SVGs, and a brand showcase page |
